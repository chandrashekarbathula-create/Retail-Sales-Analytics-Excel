# Project Screenshots

This folder contains screenshots from the Retail Sales Analytics Excel project.

## Dashboard Preview

The final dashboard provides an interactive view of retail performance across 2023–2025, including:

- Total Sales
- Total Profit
- Profit Margin
- Total Orders
- Return Rate
- Monthly Sales Trend
- Sales vs Profit by Category
- Sales by Region
- Profit Margin by Category
- Sales by Payment Mode
- Discount vs Profit Analysis
- Interactive Year Slicer
