# Excel Dashboard

This folder contains the final interactive Excel dashboard developed for the Retail Sales Analytics project.

## Dashboard Features

- Executive KPI cards for Total Sales, Total Profit, Profit Margin, Total Orders, and Return Rate
- Interactive Year slicer for 2023–2025
- Monthly Sales Trend analysis
- Sales vs Profit by Category
- Sales by Region
- Profit Margin by Category
- Sales by Payment Mode
- Discount vs Profit analysis
- Dynamic PivotTables and PivotCharts
- Business insights and recommendations

## Tools Used

- Microsoft Excel
- PivotTables
- PivotCharts
- Excel formulas
- Slicers
- Data cleaning and validation
- Interactive dashboard design

## Key KPIs

- Total Sales: ₹24.21 Cr
- Total Profit: ₹4.90 Cr
- Profit Margin: 20.25%
- Total Orders: 5,000
- Return Rate: 7.42%

The dashboard enables users to filter performance by year and analyze sales, profitability, regional performance, category performance, payment behavior, returns, and the relationship between discounts and profit.
